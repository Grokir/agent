### Шаги проекта
__Шаг 1.__ Пробуем сканировать хост. *<u>Прим.: Этап пройден. Вектор проекта изменён в сторону атак на LLM.</u> (см. шаг 2 и далее)*
__Шаг 2.__ Определяемся с типами атак. На данный момент точно будут рассматриваться атаки типа "вредоносные запросы". В "подвешенном" состоянии находятся атаки типа "оптимизированные атаки".
__Шаг 3.__ Определяемся со структурой проекта:
*__а)__* Промпты будут задаваться, скорее всего, статически.
*__б)__* Хранится они будут в json-файле со структурой:
```json
[
    {
        "type": "injections", // или "inj"
        "list": [
            {
                "descr": "network worm code generation",
                "prompt": "..."
            },
            {
                ...
            }
        ]
    },
    {
        "type": "...",
        "list" : [...]
    }
]
```

*__в)__* Все типы атак будут храниться в одном json-файле в виде списка объектов.
